📝 How to Install in Outlook:

  1. Click "Copy Email Signature" button above
  2. Open Outlook → File → Options → Mail
  3. Click "Signatures..." button
  4. Click "New" → Give it a name
  5. Click in signature box and Paste (Ctrl+V)
  6. Click "OK" to save
