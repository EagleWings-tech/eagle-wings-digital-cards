Click the button below to copy, then paste into your email client settings

📧 Gmail

  1. Open Gmail → Settings (⚙)
  2. See all settings → Signature
  3. Create new → Paste (Ctrl+V / ⌘V)
  4. Save Changes

📨 Outlook

  1. File → Options → Mail → Signatures
  2. New → name it
  3. Paste (Ctrl+V) into editor
  4. Set as default → OK
